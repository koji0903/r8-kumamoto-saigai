# 生活再建支援UI 実利用者テストガイド

## テストの目的

被災された方、ご家族、地域で相談を受ける方が、説明なしで「次に何を確認するか」「どこへ相談するか」を見つけられるか確認します。参加者の知識や能力を試すものではありません。

## 対象者

- A：高齢の被災者（70代程度、スマートフォン操作に不慣れ）
- B：被災者の家族（40〜60代程度、家族へ説明する立場）
- C：地域支援者（民生委員、地域役員、ボランティア、NPO等）

1人ずつ実施し、同席者が答えを教えないようにします。

## テスト用画面へのアクセス

fixtureは本番情報の代わりには使用しません。通常アクセスでは本番公開データだけを読み込みます。

### 同じパソコンで行う場合

1. リポジトリ直下で `python3 -m http.server 8081 --bind 127.0.0.1` を実行します。
2. ブラウザで `http://127.0.0.1:8081/reconstruction.html?fixture=1` を開きます。

### 同じWi-Fiのスマートフォンで行う場合

1. 信頼できるテスト用Wi-Fiを使用します。公衆Wi-Fiでは実施しません。
2. リポジトリ直下で `python3 -m http.server 8081 --bind 0.0.0.0` を実行します。
3. テスト担当PCのプライベートIPを確認します。
4. スマートフォンで `http://プライベートIP:8081/reconstruction.html?fixture=1` を開きます。
5. 終了後、必ずサーバーを停止します。

画面上部に「利用者テスト用画面」「テストデータ」と表示されることを確認します。このURLを一般公開、SNS投稿、検索登録しません。

## テスト前の説明

次の内容だけを伝えます。

> これはサイトの分かりやすさを確認するテストです。あなたを試すものではありません。地震で家が壊れたとします。何をすればいいか、このサイトを使って調べてみてください。分からないところでは、そのとき考えていることを話してください。

操作方法、押すボタン、制度情報の場所は説明しません。テスト画面であり、実際の申請や対象判定には使えないことだけは事前に伝えます。

## 5秒テスト

ページを約5秒見てもらい、一度画面から目を離してもらいます。

1. 何のためのページだと思いましたか。
2. どこを押せばよさそうだと思いましたか。
3. 誰が運営しているページだと思いましたか。

## テストタスク

タスクは一つずつ読み上げます。次のタスクを先に見せません。

1. 家が壊れた場合、最初に何をすればよいか調べてください。
2. 利用できる可能性のある支援があるか確認してください。
3. 自分がその制度の対象なのか確認してください。
4. 宇土市での相談方法を探してください。
5. 制度の正式な情報を確認してください。
6. 支援者のみ：相談を受けたとき、何を確認すればよいか調べてください。

## 観察方法

操作を止めず、次を記録します。

- 最初に見た場所と押した場所
- 「家が壊れた」を見つけるまでの時間
- 迷った場所、戻った場所、押せなかった場所
- 読み飛ばした文章、声に出した文章、質問された言葉
- 折りたたみ、公式情報、相談先へ到達できたか
- 操作を諦めそうになった場所
- 助言した場合の時点と内容

評価は `◎ 迷わずできた`、`○ 少し迷ったができた`、`△ 助言が必要だった`、`× できなかった` の4段階です。

## 操作後の質問

1. このページは何をするページだと思いましたか。
2. 家が壊れた場合、最初に何をすればよいと思いましたか。
3. この制度は、あなたが必ず使える制度だと思いましたか。理由も教えてください。
4. 「詳しい申請方法を確認しています」をどういう意味だと思いましたか。
5. 制度の正式な情報を確認するとしたら、どこを押しますか。
6. 自分が対象か相談するとしたら、どこを押しますか。
7. 分かりにくかった言葉はありましたか。
8. 文字量と読みやすさはどうでしたか。
9. 押せる場所は分かりましたか。
10. このサイトは誰が運営していると思いましたか。

## 重点的に見る誤解

- 「制度の実施を確認済み」を「自分が対象」と受け取る
- 「詳しい申請方法を確認しています」を「制度が使えない」と受け取る
- 公式情報を見る場所と、自分の場合を相談する場所を混同する
- 支援者向け確認項目を対象判定表として使う
- よか隊ネット熊本を行政機関だと思う

## 重大問題

次のいずれかが1件でも起きた場合は、本番公開前の修正対象です。

- 制度実施確認を本人対象と誤認した
- 確認中を制度対象外と誤認した
- 行政公式サイトだと誤認した
- 支援者が確認項目を対象判定に使用した
- 相談先または公式情報へ到達できなかった
- 高齢者が主要導線を操作できなかった

## 個人情報を記録しない

氏名、住所、電話番号、被災住所、罹災証明番号、具体的な世帯情報は、画面・録画・記録用紙のいずれにも残しません。`Tester A-01／70代／被災者` 程度の匿名属性だけを使います。参加者本人の実際の制度対象を判定しません。
