## お願い

このテストは、ページの分かりやすさを確かめるものです。あなたを試すものではありません。分からないときは、そのまま「分からない」とお答えください。

回答者：被災された方／ご家族／地域で相談を受ける方／その他

使用した端末：スマートフォン／タブレット／パソコン

## 質問

1. ページを5秒ほど見て、何をするページだと思いましたか？

2. 「地震で家が壊れた」とき、最初にどこを押すと思いましたか？ 実際に押してみてください。

3. 次に何をすればよいか、自分の言葉で説明してください。

4. 「制度の実施を確認済み」は、あなた自身が制度を使えるという意味だと思いましたか？ どう受け取ったか教えてください。

5. 「詳しい申請方法を確認しています」を見て、制度を使えないと思いましたか？ どう受け取ったか教えてください。

6. 制度の内容を確認する公式情報は、どこから見られましたか？

7. 自分の場合について相談する場所は分かりましたか？ 分からなかった場合は、どこで迷いましたか？

8. 文字の大きさ、文章の長さ、ボタンの押しやすさはどうでしたか？

9. 分かりにくい言葉や、行政の公式サービスだと感じた箇所はありましたか？

10. 家族や近所の方へこのページを案内するとしたら、困りそうな点を教えてください。
