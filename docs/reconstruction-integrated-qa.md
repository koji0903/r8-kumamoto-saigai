# 「暮らしの再建」統合QA・横断レビュー

実施日: 2026-08-11  
対象: 一般社団法人よか隊ネット熊本「暮らしの再建」情報群  
位置づけ: 公的機関の一次情報を見つけやすくする民間の情報ナビ。申請受付、診断、認定、制度対象判定は行わない。

## ページ台帳と固有の役割

| 分野 | 入口 | 固有の役割 |
|---|---|---|
| 全体 | `reconstruction.html` | 8カテゴリの入口、複数の困りごとの整理、専門機関・公的機関への参照 |
| 住まい | `reconstruction-official.html?category=home` | 21市町村の住まい関連公式情報。宇土市だけは確認済み情報を整理した `uto-housing.html` へ補助導線 |
| お金・支払い | `reconstruction-money.html` | 生活費、支払い、収入減等を平易な言葉で整理し、公式情報へつなぐ |
| 証明・申請 | `reconstruction-documents.html` | 罹災証明、必要書類、期限等の確認観点を整理し、公式情報へつなぐ |
| 健康・介護 | `reconstruction-health-care.html` | 医療、こころ、薬、介護等を整理。緊急時の情報探索継続を防ぐ |
| 子ども・家族 | `reconstruction-family.html` | 学校、保育、子育て、家族の生活を整理。個人情報を入力させない |
| 仕事・事業 | `reconstruction-work-business.html` | 雇用と事業を分けて整理し、公的機関等へつなぐ |
| 農業・漁業 | `reconstruction-agriculture-fishery.html` | 農業・漁業の被害と再開を分けて整理し、自治体公式情報へつなぐ |
| 暮らし・移動 | `reconstruction-official.html?category=daily_life` | 交通、道路、ライフライン、日常生活の自治体公式情報を横断表示 |
| 自治体公式情報 | `reconstruction-official.html` | 市町村と8カテゴリを選ぶ共通検索面。自治体を混在表示しない |

住まいと暮らし・移動は、未確認の説明カードを増やさず、現時点では公式情報ナビを固有の役割とする。専用ページがないことを「制度がない」とは表示しない。

## 周辺ページとの関係

- `index.html`: 団体ホームから「暮らしの再建」へ直接進む入口。
- `disaster.html`: 発災直後を含む災害支援ポータル。生活再建の整理が必要な人を本機能へ送る。
- `affected.html`: 困りごと起点の短い初動導線。生活再建に進む二次導線を持つ。
- `supporters.html`: 支援方法とボランティア情報。本人向けの制度対象判定とは混在させない。
- `municipalities.html` / `municipality-updates.html`: 自治体別の全情報と時系列発信。本機能はそこから生活再建8カテゴリを抽出する。
- `shelters.html`: 現在の避難先情報であり、生活再建制度とは分離する。
- `uto-housing.html`: 宇土市が公表した住まい情報の読み解きページ。熊本県全体の共通制度と誤認させない。

## 優先度別の確認結果

### P0

該当なし。個人情報の送信・保存、自治体間の情報混在、虚偽の「制度なし」表示は確認されなかった。

### P1（今回修正）

- 8カテゴリの正式名を「証明・申請」に統一した。
- 完成済みの専用ページがあるのに汎用公式情報ページへ戻っていた関連リンクを、専用ページへ接続した。
- 再建カテゴリ配下でグローバルナビの「暮らしの再建」が選択状態になり、パンくずを `ホーム > 暮らしの再建 > カテゴリ` とした。
- 統合QAをGitHub Actionsへ追加し、ページ欠落、空リンク、カテゴリ逸脱、保存API、21市町村、HTTPS、フォーカス、印刷、モバイルCSSを継続検査する。

### P2

- 金額、期限、電話番号を未確認のまま補完せず、確認済みカードと自治体公式発信を分離している。
- 公式情報が0件の場合は「制度がない」ではなく「現在確認しています」と表示し、自治体公式トップへの代替導線を常に残す。
- JavaScript無効時にも市町村一覧、8カテゴリ、暮らし整理ナビへの代替リンクがある。
- 各専用ページに支援者向け説明と運営主体・非公式性の説明がある。

### P3 / 継続監視

- カテゴリ別ページは成立時期の違いからCSSファイルが分かれている。色、文字サイズ、カード、余白、フォーカス、印刷の基本規則は共通化済みだが、完全なコンポーネント統合は今後の保守課題。
- 住まい、暮らし・移動は汎用公式情報ナビを使う。根拠が十分にそろう前に説明カードを増やさない。

## 表示・安全性レビュー

- 8カテゴリ名と並び: 住まい / お金・支払い / 証明・申請 / 健康・介護 / 子ども・家族 / 仕事・事業 / 農業・漁業 / 暮らし・移動。
- 選択内容: URL送信、サーバー送信、localStorage、sessionStorage、Cookieへの保存を行わない。
- アクセス解析: 共通ページ閲覧タグのみ。チェック項目や困りごとの選択内容をイベント送信しない。
- 自治体選択: 21市町村から1自治体を明示選択し、別自治体の結果を混ぜない。不正なURLパラメータは未選択として扱う。
- 公式情報: 自治体名、正式タイトル、発表日、外部リンクを表示。表示対象がない場合も公式サイトへのリンクを残す。
- 民間・団体情報: 自治体公式カードと同じ見た目・同じ結果一覧へ混在させない。
- 緊急情報: 健康・介護では生活再建情報より前に緊急時の行動を示す。他カテゴリでは緊急通報窓口であるかのような表現をしない。
- キーボード: スキップリンク、ネイティブボタン・選択欄、`:focus-visible` を使用。
- モバイル: 主要コンテナは固定幅でなく、狭い画面で1列化する。横方向の意図しないはみ出しを抑制。
- 印刷: 操作部を整理し、選択結果・公式URLを紙面で確認可能にする。
- SEO: 各ページに固有title、description、canonical、OGPを付与し、サイトマップへ掲載。

## 自動分類の品質と残る注意点

自治体発信は高・中信頼度の分類だけを表示する。農業・漁業の「のり」は交通名称等の誤検出を避け、「海苔」「ノリ養殖」等の具体語で判定する回帰テストを持つ。一方、次は人による継続確認が必要である。

- 「福祉」「施設」「道路」など複数カテゴリにまたがる語の文脈判定。
- 自治体ページの改題、移転、削除、公開日の欠落。
- 国・熊本県の情報と市町村独自条件の差異。自動で一つの条件へ統合しない。
- 期限、金額、電話番号、対象条件は一次資料との人手照合が完了したものだけ説明カードへ反映する。

## STEP 25 本番導線への統合（2026-08-11）

- トップ: 緊急・支援情報ポータルを先、暮らしの再建を次に並べ、役割を視覚的に分離した。
- 被災者向け: 「制度名」ではなく、暮らしを立て直す困りごとから入る主要カードへ統合した。制度一覧は既存URLで維持する。
- 支援者向け: 「相談を受けながら公式情報を確認する」入口を追加し、制度対象判定ではないことを併記した。
- 自治体別: 21市町村の内部IDを既存マスタと照合し、選択自治体を `municipality` で暮らしの再建へ引き継ぐ。
- カテゴリ: 暮らしの再建トップから専用カテゴリへ移動しても自治体を保持する。無効IDは表示・引き継ぎしない。
- 住まい: 宇土市選択時だけ `uto-housing.html` を提示し、他自治体は各自治体の公式住宅情報ナビとfallbackを使う。
- 戻る導線: カテゴリの公式情報結果から、選択中の自治体別ページへ戻れる。
- JavaScript無効時: トップ、被災者、支援者、自治体別の静的HTMLから暮らしの再建へ移動できる。
- 共通ナビ: グローバルナビとフッターの既存「暮らしの再建」を維持し、項目を重複追加しない。
- キャッシュ: 共通CSS/JSのバージョンを更新し、旧表示の残留を避ける。

検証は `node scripts/test-reconstruction-production-entry.mjs` で行う。トップ、被災者、支援者、21市町村、パラメータ、宇土市分岐、noscript、SEO/OGP、Storage非使用を継続検査する。
