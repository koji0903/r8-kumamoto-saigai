# 「次に確認すること」アクションナビ

更新日: 2026年8月12日

## アクションナビの役割と行動カテゴリ

制度一覧や対象判定ではなく、利用者が公的な一次情報へ進むための「次に確認すること」を原則3件以内で示す。内部では `general_navigation`（カテゴリ・自治体公式情報への案内）と `program_specific`（検証済み制度固有行動）を分ける。独自の緊急度や優先順位は付けない。

## nextAction・高リスク・doNotDoYet

制度固有行動は既存 `next-actions.json` を再利用し、`publicationStatus: published`、`verificationStatus: verified`、有効な公的 `sourceLink` の全条件を満たす場合だけ公開用JSONへ出す。契約・支払、期限、写真、医療、安全、解体、修理に関係する行動は高リスクとして、警告アイコンと文字、`doNotDoYet` を併記する。現在登録済み2件は `draft / partially_verified` のため本番には表示しない。

## 自治体依存と8カテゴリ

住まい、お金、証明・申請、健康・介護、子ども・家族、仕事・事業、農業・漁業、暮らし・移動の8カテゴリに同じカードを使う。一般ナビは制度内容の確認済み表示とは区別し、選択自治体を `municipality` パラメータで公式情報ナビへ引き継ぐ。未選択時は自治体固有の申請方法を断定せず、先に市町村選択を案内する。

## 複合課題・公式情報・0件

暮らし整理ナビから複数分野を選んだ場合も、各カテゴリの一般ナビを1件ずつ選択順で確認でき、独自スコアは使わない。制度固有行動が0件でも「やることはない」とせず、自治体公式情報への導線を必ず残す。確認後は「ほかの困りごとも整理する」から整理ナビへ戻れる。

## 支援者・印刷・アクセシビリティ

「本人と一緒に公式情報を確認する案内」と明記し、支援者の指示表や判定表にしない。氏名・住所等の記入欄は作らない。印刷ではカードとURLを相談メモとして残す。カードは見出し構造、44px以上のリンク、明瞭なキーボードフォーカスを備え、警告は色だけでなくアイコンと文字で表す。760px以下は1列になり、320〜430pxでも左右余白を抑える。

## source変更・公開安全弁

既存運用ポリシーの `sourceDecision` は、検証済み根拠のハッシュ変更時に `needs_review` を返す。再確認中の行動は公開フィルターから除外される。sourceLinkなし、inactive source、`partially_verified`、`needs_review`、draftはいずれも制度固有行動として出さない。

## UI共通化・JavaScript無効・Privacy

`reconstruction-action-nav.js` と `reconstruction-action-nav.css` を全カテゴリで共有し、カテゴリ別実装を増やさない。JavaScript無効時も各ページ既存の `noscript` から自治体公式一覧へ進め、暮らしトップの詳細には静的な「次に確認すること」を置く。チェック状態の保存、Storage、Cookie、行動別Analytics送信は実装しない。

## 今回実装しなかったものと次の開発

制度対象判定、法律・医療判断、AI優先順位、期限の推測、未検証行動の表示、チェック状態保存は実装していない。次は人手レビューで既存2件を一次資料と照合し、Reviewer・Secondary Reviewer・Approverの記録が揃ったものだけを `published / verified` に移行する。
