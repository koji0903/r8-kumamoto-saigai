## 資料間で表記が異なる点

`uto-repair.html` は次の点をページ上で明示しています。

- 資力の要件: 公式ページ本文は全判定に資力要件がかかるように読めるが、「被災者の皆様へ」PDF・様式第1号・申込チェックシートでは資力に関する申出書は中規模半壊・半壊・準半壊の場合。
- 証拠写真代替資料の様式番号: 別紙1では「様式第8号」、公開様式では「様式第9号」（様式第8号は工事写真台帳）。
- 問い合わせ先: PDFは代表電話、公式ページは直通電話。
- 別紙1は国の資料をもとにした全国共通の例示のため、「台風」「浸水」など地震以外の表現を含む。
