# 参照資料の保存方針

このフォルダには、サイトの根拠として参照した一次資料と取得時点の原データを保存します。内容を編集してサイト用データとして利用せず、整理・要約・抽出した結果は `../data/` に保存してください。

- `hinokuni-meetings/`: 火の国会議の原本PDF。サイトから原資料として直接リンクします。
- `official/`: 熊本県などの公式サイトから取得したJSON・GeoJSON・PDF、および出典追跡用の抽出結果。

ファイルを追加するときは、取得日・会議回・公表時刻が分かる名前を維持してください。公式情報は更新される可能性があるため、上書きせず時点別に保存します。
