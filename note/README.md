# よか隊ネット熊本 Note連絡ブログ 運用管理＆全16回連載一覧（代表理事視点）

このフォルダは、「一般社団法人よか隊ネット熊本」公式Note（連絡ブログ）に投稿する連載記事原稿（全16回）および個別のアイキャッチサムネイル画像を管理するディレクトリです。

本連載は、**代表理事・土黒 功司（ひじくろ こうじ）の視点（一人称：「私」「私たち、よか隊ネット熊本」）**から、10年前の2016年熊本地震の教訓と、今年7月の令和8年熊本地震における「公的支援をやさしく届ける」「日々の記録を後世へ残す」という使命を込めて執筆されています。

**Noteのエディタに貼り付けるだけで自動的にブログカードやリンクとして認識されるよう、記事内のすべてのリンクを `https://www.yokatainet.jp/` の完全なフルパスURLで記載しています。**

---

## 運用方針・執筆ガイドライン（代表理事メッセージ基準）

1. **トーン＆マナー**
   - 被災当事者への深い共感と敬意を払い、一人ひとりの「暮らし」に寄り添う温かく力強い語り口。
   - 10年前の熊本地震（車中泊支援、みなし仮設支援）、令和2年7月豪雨（お茶処運営）の実体験に基づく実践的なアドバイス。
   - 行政を批判するのではなく、「行政が用意してくれた支援を、被災者が100%使い倒せるよう通訳する」という協調の姿勢。

2. **2つの核心的メッセージ**
   - **「公的支援をやさしく届ける」**：複雑な支援金や制度を噛み砕き、必要な人へ迷わずつなぐ。
   - **「未来へつなぐ生きた記録」**：現場の歩みや「火の国会議」の議事録アーカイブを、後世の防災・復興に活かす。

3. **出典と公式誘導の明記**
   - 制度や申請期限の詳細は日々変化するため、必ず市町村や県の公式窓口・公式発表を確認するよう案内を添える。
