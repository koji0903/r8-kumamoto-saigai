# 【代表メッセージ・第5回】被災者支援69制度を簡単検索！地元・宇土市の「支援ハンドブック＆暮らしの支援ガイド」徹底活用術

こんにちは。一般社団法人よか隊ネット熊本、代表理事の土黒 功司（ひじくろ こうじ）です。  
私たちのWebサイト活用ガイド、連載第5回をお届けします。

今回から4回にわたり、被災の大きかった各自治体の支援制度を深掘りする「自治体特化編」をお届けします。  
その第1弾として取り上げるのは、私たちよか隊ネット熊本の本拠地（宇土市走潟町）がある、**宇土市（うとし）**です。

宇土市は今回の令和8年熊本地震において、市街地から沿岸部・山間部に至るまで震度7・6強の激震に晒され、道路の地割れ、住宅の倒壊・傾き、激しい断水など甚大な被害を受けました。  
私の自宅や拠点も激しく揺れ、近所の方々と声を掛け合いながら避難したあの日を忘れることはありません。

宇土市役所は発災後、極めて手厚い支援策や独自の補助金を打ち出し、分厚い「被災者支援制度ハンドブック」を発行しました。  
しかし、避難生活や片付けに追われる市民の方々から、現場で毎日のように聞かれたのは、次のような悲鳴でした。

> **「全部で何十ページもあって、文字が小さくてどこを読めばいいのかわからない」**  
> **「うちは準半壊なんだけど、何がもらえて、何の手続きが必要なの？」**

そこで私たちは、宇土市公式の**全69制度をスマホで一発検索できる専用ツール**を開発し、Webサイトに公開しました。

今回は、**『宇土市 暮らしの支援・補助金総合ガイド』**と**『宇土市 被災者支援制度ハンドブック検索ガイド』**の賢い使い方と、見逃してはならない宇土市独自の支援制度をお伝えします。

## 1. 全69制度を一発絞り込み！「ハンドブック検索ガイド」

宇土市の「被災者支援制度ハンドブック検索ガイド」は、紙の冊子をめくる必要が一切ありません。

画面上で、
1. **あなたの罹災証明書の判定**（全壊 / 大規模半壊 / 中規模半壊 / 半壊 / 準半壊 / 一部損壊）
2. **知りたい分野**（住まい / くらし・生活 / お金・貸付 / 医療・福祉 / 税・保険料減免 / 子育て / 農業・事業者）
をタップするだけで、**「あなたが対象になる制度だけ」が瞬時に絞り込まれて一覧表示**されます。

それぞれの制度カードには、
- **もらえる金額・支援内容**
- **申請に必要な書類**
- **申請期限**（締め切り）
- **宇土市役所の担当課直通電話番号**
が整理されており、電話番号をタップすればその場ですぐに役所の担当者へ問い合わせができます。

## 2. 宇土市民が絶対に見落としてはならない注目制度

数多くの制度の中でも、特に見落としがちな宇土市の独自支援をピックアップします。

### ① 宇土市独自の被災世帯見舞金・一部損壊支援
国の被災者生活再建支援金は「中規模半壊以上」でなければ1円も出ません。しかし、宇土市では「準半壊」や「一部損壊」であっても、市独自の見舞金や住宅復旧支援制度が用意されている場合があります。「一部損壊だから諦める」のではなく、必ずハンドブック検索で確認してください。

### ② 固定資産税・軽自動車税の減免
半壊以上の被害を受けた住家や、土砂崩れ・地割れで損壊した土地、地震で水没・廃車となった軽自動車について、申請により今年度の税金が全額または一部減免されます。申請しないと自動では減額されませんので注意が必要です。

### ③ 上下水道料金の基本料金免除
地震による断水や宅内漏水に見舞われた地域の世帯を対象に、水道基本料金の減免措置が実施されています。

## 3. 「広報うと 災害臨時号」のデジタル再構成

宇土市が全戸配布した「広報うと 災害臨時号vol.1」を、スマホで読みやすくカテゴリ別に並び替えた専用ページも公開しています。

「罹災証明をもらった後の流れ」「ごみ処理」「相談窓口」といった目的別の目次を設け、さらに**市役所が「詳細は決まり次第お知らせします」としている未定の項目もそのまま正直に掲載**しています。今できることと、まだ待つべきことの線引きが明確にわかる設計です。

▼ 広報うと 災害臨時号デジタルナビ  
https://www.yokatainet.jp/uto-bulletin.html
